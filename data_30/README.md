# 수정30: 읽기 쉬운 서술과 접근정보 범위 재확인

2026-10-18 사용자 PDF 주석 7건과 문장 연결 요청을 반영했다. 계산 모형과 거리 결과는 data_29의 22개 출발점 모형을 유지하며, 이번에는 서술·집계 범위·제안 역할·평가 절차를 보완했다.

`peer_access_recheck.json`과 `peer_access_recheck.md`는 하위 에이전트의 원본 직접 재집계다. 원시 OSM에서 반경 500m의 출입구 22개를 다시 선정한 결과 wheelchair 항목 미기재 20개, yes 1개, no 1개로 data_29/accessibility.csv와 일치했다. 이는 이번 OSM 항목의 공백이며 공식 기관의 출입구·승강기 정보가 없다는 뜻이 아니다.

`AI_추출과_검수시간_평가방법.md`는 별도 실험을 준비할 때 쓸 절차이며, 두 CSV는 빈 기록 양식이다. 사람 정답표·새 AI 원출력·참여자 작업시간을 채우기 전에는 정확도나 시간 절감 수치를 생성하지 않는다. CSV에 실제 참가자 개인정보를 넣을 필요는 없으며 참여자 ID로 기록한다.

PDF에서는 ‘검토서’라는 갑작스러운 명칭과 ‘초안 2건을 생성했다’는 문장을 삭제하고, 이용자가 우회 사실을 어디서 알게 되는지 설명한 뒤 가는 길·승차 대안을 공지에 함께 싣는 제안으로 연결했다. 수원시 담당부서·8800번 버스회사의 운행 변경 준비와 서울 현장 기관의 통제·정차 협의는 이번 분석의 협업 제안으로 구분했으며, 특정 법적 권한을 확정한 설명은 아니다.
