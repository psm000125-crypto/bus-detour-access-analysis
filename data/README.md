# 분석 자료 안내

보고서에 사용한 입력자료, 출처 대조 자료와 계산 결과를 이 폴더에 모았습니다. **현재 분석의 기준은 출발점 22개·안내 후보 50개·추가 안내 2곳의 조합 1,225개**입니다.

## 입력자료

| 파일 | 내용과 용도 |
|---|---|
| `settings.json` | 좌표계·기존 승차지·지도 대체지점·출발점과 후보 선정 규칙 |
| `stops.csv` | 서울시 정류소 자료 중 선택한 6개 정류소. ID는 앞자리 0을 포함한 문자열 |
| `service_changes.json` | 수원시 공지의 8800·M5107 우회 시간, 미경유 정류소, 승차 위치 사실 전사 |
| `raw/osm_initial.json` | 공식 정류소와 건물 대체점 등 기초 위치를 정하는 지도 추출본 |
| `raw/osm_network.json` | 22개 출발점과 보행망을 구성하는 확대 지도 추출본 |
| `raw/*_query.txt`, `raw/osm_network_headers.txt` | 지도 요청문과 제공 서버 응답 정보 |

확대 추출본의 요청 범위는 `(37.545,126.958,37.578,127.003)`이며, OSM 노드 26,902개와 way 5,845개를 포함합니다. 기존 정류소에서 추출 경계까지 최소 거리는 약 1,163m입니다. 출발점은 기존 정류소 반경 500m에 있는 OSM 지하철 출입구를 연결 여부와 무관하게 선정했습니다.

지도는 `https://maps.mail.ru/osm/tools/overpass/api/interpreter`에서 취득했습니다. 요청문은 `[date:"2026-04-04T22:00:00Z"]`로 과거 기록을 지정합니다. 응답의 `timestamp_osm_base=2026-10-17T07:45:21Z`는 제공 서버의 갱신 시각으로, 요청한 지도 시점과 구분합니다. 원응답과 요청문은 바꾸지 않고 보존했습니다.

## 출처 대조와 보조 입력

| 파일 | 내용 |
|---|---|
| `ai_notice_extraction.json` | TOPIS 공지 5건의 선정 규칙·원문 전사·AI 추출값·별도 AI 대조값 |
| `facility_sources.json` | GTX-A·공항철도의 접근시설 공식 안내와 지도 대응 범위 |
| `carbon_parameters.json` | 국내 가이드라인의 휘발유 CO2 계수·가정 연비·해석 범위 |
| `policy_reference.json` | 네 정책 지표와 출발점별 손익에 대한 별도 계산 대조값 |

출처 대조 자료의 과거 상대경로·해시는 당시 계산의 근거 식별자입니다. 현재 파일의 위치와 배포 해시는 루트의 `BUNDLE_MANIFEST.json`에서 확인합니다.

## 결과 확인

`results/`에 현재 모형의 결과를 수록했습니다. 정책 요약은 `policy_summary.csv`, 출발점별 상세값은 `journeys.csv`, 세 비교 기준별 손익은 `baseline_differences.csv`에서 확인합니다. 전체 파일 설명과 거리 변수 정의는 [실행 안내](../CODE_README.md)에 있습니다.

OSM의 일반도로 보행과 지도상 투영점을 사용하며, 떨어진 선형 사이에 임의 연결을 추가하지 않습니다. 버스 승객용 열린 승강장 선형은 기존 공유 노드로 연결하고 접근·방향·면 제한을 유지합니다. 접근성 점검에서는 출발점을 고정한 채 계단과 명시된 제한을 제외합니다. 지도상 연결 결과는 현장 통행·엘리베이터 가동·휠체어 승차 가능성과 구분해 해석합니다.

원자료의 제공기관과 이용 조건은 [데이터 출처](../SOURCE_NOTICE.md)에 정리했습니다.
