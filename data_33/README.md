# 최종 권고: 최대 추가보행 최소 배치

수정일: 2026-10-18. 공간 모형과 원거리 결과는 `data_29` 그대로이며, 이번 수정은 그 결과에서 정책을 선택하는 우선순위를 바꾼 것이다. **최대 추가보행을 먼저 최소화하고, 같은 최댓값의 배치에서는 합계를 최소화하는 `equity`를 최종 권고한다.** 이는 기존 계산 코드의 선택 순서와 같다.

## 선택 근거

합계 최소안과 비교하면 최대 추가보행은 1,374.899582m에서 1,007.156906m로 26.746875% 줄고, 22경로 추가보행 합계는 7,280.417148m에서 7,327.355508m로 46.938361m(0.644721%) 늘어난다. 큰 추가부담을 먼저 줄이는 목적에 따라 이 차이를 받아들이는 선택이다. 모든 경로가 좋아지는 배치나 실제 집단 간 형평성 개선을 입증한 결과는 아니다.

합계 최소안 대비 경로별로 4개 개선·10개 악화·8개 동일이다. 도달 경로 수 우선안 대비는 11개 개선·11개 악화이며, 두 비교를 섞지 않는다. 전체 이동거리 최댓값도 합계 최소안의 3,384.182022m에서 3,588.598695m로 늘어나는 비용을 함께 제시한다.

첫쪽 그림과 평균 구성도 새 권고안으로 바꿨다. 평균 전체 거리 원값은 2,355.545601m이므로 10m 단위 표시가 2,360m이고, 성분은 각각 520m·1,500m·330m다. 개별 반올림 때문에 표시 성분 합과 표시 전체 사이에 10m 차이가 생길 수 있음을 그림에 알렸다. 늦은 인지가 차지하는 분모는 기존보다 늘어난 거리이며 그 비중은 약 18%다.

## 보완 조건

도달수 우선안보다 길어진 11개 경로를 출입구 사전 안내와 승차 대안의 보완 대상으로 둔다. 추가 표지나 배치 변경은 먼저 만나는 안내를 바꿀 수 있어, 추가 수량·설치비와 전체 22개 경로를 다시 계산하고 기본안의 최대 추가보행을 높이지 않는 대안만 채택하도록 제안한다. 현재 후보 50개·안내 2곳 조건의 최적안에서 합계가 반드시 더 줄어드는 배치가 있다고 주장하지 않는다. 보완을 위한 새 안내 배치나 예산을 이번 수정에서 실제로 확정한 것은 아니다.

이동이 어려운 경로에는 실제 계단 없는 연결·다른 승차지·연결수단을 별도로 확인한다. 출발점별 지도 거리의 상한 보호를 장애·연령·소득별 실제 이동 격차 해소의 측정 성과로 부르지 않는다.

## 파일과 실행

- `verify_policy_choice.py`: 표준 라이브러리로 원거리 CSV를 읽어 통계·정책 손익·별도 에이전트 대조값을 확인한다.
- `policy_choice.json`: 최종 권고·두 대조 기준·평균 구성·반올림·보완 범위·입력 해시.
- `policy_differences.csv`: 두 비교 기준 각각의 22경로 손익, 총 44행.
- `peer_policy_review.md/json`: 별도 에이전트가 직접 재계산한 정책 검토와 원값.
- `peer_final_review.md`: 수정된 보고서 문장의 별도 검토.

저장소 루트에서 `python data_33/verify_policy_choice.py`로 실행하며 네트워크·AI API·지도 재취득은 없다. 기존 `data_31`의 합계 최소 권고 관련 파일은 수정31 당시의 기록이며 최종 권고를 설명할 때는 `data_33`을 우선한다. 공식 시설·AI 공지 대조·탄소 입력 근거는 계속 `data_31`과 `data_17`을 사용한다.
