# 버스 임시우회 안내의 도달 범위와 이동 격차

팀 **금오안옴**의 교통문제 해결 데이터 분석 공모전 보고서와 분석 코드입니다.

버스가 임시우회할 때 안내를 늦게 접해 발생하는 추가보행을 분석했습니다. 서울역 주변 출발점 22곳과 안내 후보 50곳에서 추가 안내판 2곳의 배치 1,225개를 비교하고, 가장 많이 돌아 걷는 경로의 부담을 줄이는 배치를 제안합니다.

## 핵심 결과

권고 배치는 기존 정류소에만 안내가 있는 비교모형보다 **최대 추가보행을 약 1,600m에서 1,010m로 37% 줄였습니다.** 22개 경로 중 11개가 짧아지고 11개는 같았습니다. 추가보행은 승차지 변경 자체로 늘어난 거리와 구분하며, 우회를 늦게 알아 더 걷는 거리입니다.

| 비교 기준 | 권고안에서 짧아진 경로 | 동일한 경로 | 길어진 경로 |
|---|---:|---:|---:|
| 기존 정류소에만 안내 | 11 | 11 | 0 |
| 도달 경로 수 최대 배치 | 11 | 0 | 11 |
| 추가보행 합계 최소 배치 | 4 | 8 | 10 |

권고안은 최대 추가보행을 먼저 줄이고, 최댓값이 같으면 합계를 줄이는 기준으로 선택했습니다. 다른 배치보다 길어진 경로의 보완과 임시 승차지까지의 접근 부담을 함께 검토하는 정책 절차를 제안합니다.

## 실행

Python 3.12 환경에서 의존성을 설치한 뒤 실행합니다.

```powershell
python -m pip install -r requirements.txt
python run_analysis.py
```

설치 후 계산은 저장소에 포함한 입력자료로 수행합니다. 결과표와 경로 검산, 공지 추출 대조, 단위 테스트를 한 번에 실행합니다.

## 해석 범위

결과는 공개 지도와 고정 접근경로에 따른 조건부 비교입니다. 현장 보도·횡단·행사 통제·엘리베이터 가동·실제 승차 가능성 및 안내 인지율은 현장 조사로 확인해야 합니다. 탄소 계산은 전환율 등을 가정한 산술 예시이며 실제 감축 성과와 구분합니다.
