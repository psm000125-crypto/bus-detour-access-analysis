# 버스 임시우회의 정보 지연과 승차 접근 부담

팀 **금오인데 버스안오**의 공개자료 기반 공모전 분석 코드와 재현 자료입니다.

공식 우회 사례에서 안내로 줄이는 정보 지연과 미리 알아도 남는 승차 접근을 구분합니다. 정책 제안은 우회 계획의 승인·협의 단계에 **대체 승차 접근 검토서**를 도입하는 것입니다. 승인 절차의 현행 의무를 설명하는 것이 아니라 연구에서 제안한 개선안입니다.

## 재현

Python 3.12 환경에서 [실행 안내](CODE_README.md)에 따라 의존성을 설치하고 `python run_analysis.py`를 실행합니다. 동봉 입력으로 공간 주 분석, 안내 수량·인지·경로 분석, 승차 접근 목표·보행속도·탄소 입력 가정을 재계산하고 모형 테스트 26개를 실행합니다.

## 핵심 결과와 해석

- 출입구 22개 중 계산 가능 21개·연결 미해결 1개를 보존했습니다. 같은 추가 안내 2곳에서 최다 여정안 대비 최대 추가길이를 약 962m에서 649m로 줄이는 조합이 있었습니다.
- 선택 안내 2곳의 평균 접근은 기존 접근 419m·승차지 변경 1,598m·정보 지연 236m입니다. 증가한 거리 합에서 승차지 변경 비중은 87.1%입니다. 실제 시민 불편이나 절감 가능 비율이 아닙니다.
- 두 위치 변경 가정은 이용 가능한 승차 접근을 가정한 기하상 비교입니다. 통제일 버스 진입·정차·안전·운영 가능성을 확인한 후보가 아닙니다.
- 거리값·보행속도·자동차 전환율은 민감도 입력입니다. 탄소 표는 미국 EPA 참고 계수를 사용한 회피 자동차 배기관 성분이며 정책 순감축 성과가 아닙니다.
