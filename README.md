# 버스 임시우회 안내의 사각지대와 승차 접근 부담

팀 **금오인데 버스안오**의 공개자료 기반 분석 코드와 재현 자료입니다.

## 실행

[실행 안내](CODE_README.md)에 따라 Python 3.12 환경을 준비한 뒤 `python run_analysis.py`를 실행합니다. 현재 분석은 `data_13/recompute_expanded.py`이며, 코드 검증과 모형 테스트 16개를 함께 실행합니다.

## 결과와 해석

출입구 22개 중 21개 여정을 계산하고 추가 안내 2곳의 후보 조합 1,378개를 비교했습니다. 같은 안내 수량에서 여정 수 우선 배치 대비 최대 추가 지도 길이가 약 962m에서 649m인 조합이 있었으며, 2개 여정이 짧고 19개는 같았습니다.

일반도로 보행·지도 대체점·고정 접근 경로를 가정한 조건부 결과입니다. 실제 보도·횡단·행사 통제·임시 대기 위치·승객 수·인지율은 확인하지 못했습니다. 실제 정책 효과나 탄소 절감량을 측정한 연구는 아닙니다.
