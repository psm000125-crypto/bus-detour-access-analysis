# 버스 임시우회 안내의 도달 범위와 이동 격차

팀 **금오안옴**의 공모전 분석 코드와 재현 자료다. 현재 보고서는 `data_29`의 22개 출발점 모형을 사용한다.

## 실행

Python 3.12 환경에서 [상세 실행 안내](CODE_README.md)에 따라 의존성을 설치하고 `python run_analysis.py`를 실행한다. 현재 모형만 계산하려면 `python data_29/reanalyze_platforms.py`, 독립 검산은 `python data_29/peer_verify_policy.py`다. 패키지 설치 뒤 계산은 동봉 입력으로 수행하며 AI API를 호출하지 않는다.

## 현재 결과

- 서울역 9-1출구 연결을 포함한 출발점 22개·후보 50개·추가 2곳 조합 1,225개.
- 같은 안내 2곳의 도달수 우선 배치는 최대 추가보행 1,392.8m, 최댓값 최소 배치는 1,007.2m. 후자는 11개 경로를 개선하고 11개를 악화시킨다.
- 최종 권고는 최대 추가보행 최소 배치다. 합계 최소안보다 최대 추가보행이 약 27% 줄고 합계는 약 50m(0.6%) 늘어난다. 전체 이동거리 최댓값은 약 3,380m에서 3,590m로 늘며, 이 기준 대비 경로별로 4개 개선·10개 악화·8개 동일이다.
- 도달수 우선안보다 길어진 11개 경로에는 사전 안내·승차 대안을 보완한다. 추가 안내의 수량·비용·전체 경로를 다시 계산해 기본안의 최대 추가보행을 높이지 않는 안만 채택하는 조건이다. 새 보완안의 실제 설치·운영 가능성을 검증한 것은 아니다.
- 수량 비교는 안내판을 고정한 채 덧붙인 것이 아니라 각 수량에서 위치를 다시 선택한 결과다.
- 기존 정류소 안내만 있는 현행 비교모형보다 권고안의 11개 경로가 짧아지고 11개는 같으며 악화는 없다. 추가 안내를 만나는 11개가 모두 개선되고 만나지 않는 11개는 기존 안내가 유지된다. 다른 두 배치 대비 결과와는 구분한다.
- 계단·표시된 접근 제한을 반영하면 새 경로 미산출 3곳·출입구 접근 제한 1곳·지도상 경로 잔존이나 현장 확인 필요 18곳이다. 실제 접근 불가 인원이 아니다.

## 모형 수정의 의미

기존 필터는 승객용 승강장 선형까지 제외했다. 버스 승객용 열린 선형 6개를 기존 공유 노드로 연결해 9-1출구와 6번승강장 접근을 복원했다. 원본 좌표나 선형을 수정하거나 직선 연결을 추가하지 않았다. 차량 전용로·통행 제한·면 승강장은 제외한다.

data_13·14·17·28은 이전 21개 출발점 모형의 보존 결과다. 이전 수치를 현재 모형과 섞으면 안 된다. data_29/analyze_revision.py도 이전 설명용이며 현재 주 분석이 아니다.

일반도로 보행과 지도상 투영 시작점을 가정한 분석이다. 현장 보도·턱·경사·횡단·행사 통제·엘리베이터 가동·휠체어 차량 승차·실제 수요·인지율은 확인하지 않았다. AI 검토는 사람 검수나 현장 접근성 인증을 대신하지 않는다. 실제 수단 전환·순탄소 효과도 측정하지 않았다.

GTX-A 공식 공지에서 서울역 1번출구 엘리베이터를 확인했고 공항철도 공식 자료에서 서울역 시설도 확인했다. 계단 제외 시 3곳은 실제 접근 불가가 아닌 지도상 연결 확인 불가로 해석한다. 공지 5건×5개 필드는 별도 에이전트 대조값과 25/25 일치했지만 사람 정답표 정확도나 검수시간 절감률이 아니다. 자세한 범위는 data_31에 있다.

이 자료는 보고서 코드 링크에서 열람·실행하는 재현용 자료다. ZIP은 같은 파일을 묶은 로컬 재현용이며, 공식 예선 필수·허용 첨부로 확인된 것은 아니다. 과거 검토문에 나오는 공개 미반영 상태는 각 수정 당시의 기록이며 현재 기준은 data_29·31·33·34와 이 README다.
