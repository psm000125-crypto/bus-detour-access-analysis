# AI 활용 기록: 09번 발전

날짜: 2026-10-17, 한국시간. 작업 환경: Codex 대화. 실제 모델 ID·추론 설정은 이 기록에서 별도로 검증하지 않았으므로 기재하지 않는다.

## 실제 수행

1. 사용자가 08번 발전과 공모 취지 반영을 요청했다.
2. AI가 기존 문서와 공식 공고를 검토하고 공식 웹 검색을 수행했다.
3. 공식 HWP·공지 HTML·노선도 이미지를 저장했다.
4. HWP의 미리보기와 본문 문단 텍스트를 추출해 필수 제출요건을 읽었다.
5. 4월 5일 공지와 이미지 3개를 판독해 8800·M5107의 `service_changes.json`을 작성했다. 없거나 검증하지 않은 값은 null로 남겼다.
6. AI가 감사 코드를 작성했고 Python으로 실행했다. 결과는 원문 사실의 독립 평가가 아닌 입력 준비상태 검사다.
7. 공모 취지에 맞는 연구질문·정보조건·보행 부담·정책 대안과 한계를 문서화했다.

## 지시와 처리 규칙

실제 사용자 지시는 “그거 이제 발전 시키자”, “공모전 취지에 맞게 발전시켜야됨”이다. 아래는 이번 처리에서 사용한 규칙을 정리한 것으로, 별도 외부 모델에 전송한 프롬프트나 원출력 로그가 아니다.

- 공식 원문에서 확인되는 값과 AI의 해석·제안을 구분한다.
- 도로 통제시간과 노선별 예정 운행시간을 다른 항목으로 기록한다.
- 임시 승하차 장소의 일반 정류소 ID를 생성하지 않는다.
- 노선 간 미경유 정류소 목록을 복사하지 않는다.
- 실제 운행·사람 행동·보행경로를 검증하지 않았다면 완료로 판정하지 않는다.
- 분석 결과 없이 거리 절감·수혜자·탄소 감축량을 생성하지 않는다.

## 후속 추출 실험용 프롬프트 제안 — 아직 별도 실행·평가 전

> 제공한 공식 원문과 첨부에서 사건일, 노선, 방향, 도로 통제시간, 노선별 예정시간, 조기 복귀조건, 미경유 정류소, 대체 승하차 지점을 각각 추출하라. 값마다 근거 파일과 표·영역을 남겨라. 대체 지점은 일반 정류소와 임시 장소를 구분하라. 임시 장소에 정류소 번호가 없으면 null로 두고 공식 장소 설명을 보존하라. 원문에 없는 방향·좌표·보행경로·실제 운행을 추측하지 말라. 서로 다른 적용 범위의 시간을 덮어쓰지 말라. 원문 충돌은 보류하고 양쪽 근거를 남겨라.

## 평가·검수 상태

사람 정답표, 별도 평가 사건의 동일 조건 비교, 사람 검수시간, 이해도·행동 실험을 수행하지 않았다. AI 정확도·시간절감률·시민 효과 수치는 없다. 이번 AI 작성 자료를 사람이 검토한 최종 자료라고 표시하지 않는다.
