# 현재 보고서의 22개 출발점 모형

현재 보고서의 전체 설명은 [본문·표·그림·참고문헌](../REPORT.md)에서 확인할 수 있다. 최종 권고안은 기존 정류소 안내만 있는 현행 비교모형의 최대 추가보행을 1,597.210m에서 1,007.157m로 약 37% 줄이며, 현행 대비 11개 경로가 짧아지고 11개는 같아 더 길어지는 경로는 없다. 합계 최소안 대비 감소율 약 27%와는 비교 기준이 다르다.

작성일: 2026-10-18, 한국시간.

## 실행과 구분

```powershell
python data_29/reanalyze_platforms.py
python data_29/peer_verify_policy.py
python -m unittest discover -s data_29 -p test_platforms.py -v
```

의존성은 기존 requirements.txt를 따른다. 설치 후 계산은 동봉 원본으로 수행하며 AI API나 외부 지도 API를 호출하지 않는다. data_13·14·17·28은 이전 21개 모형의 보존 결과다. data_29/analyze_revision.py도 이전 설명용이며 현재 모형과 혼합하면 안 된다. 현재 결과의 진입점은 reanalyze_platforms.py다.

## 9-1출구의 미연결을 해결한 근거

기존 코드는 highway=platform을 일괄 제외했다. 그런데 원본 지도에는 출입구의 보행로와 버스 승객 공간이 공유 노드로 이어져 있었다. 현재 모형은 highway=platform, public_transport=platform, bus=yes인 열린 선형 중 기존 통행·방향·접근 제한을 통과한 6개를 보행망에 포함한다. area=yes와 폐합 승강장 외곽선, 택시용 승강장, 차량 전용로는 포함하지 않는다.

대상 선형은 331994921, 331994922, 331994923, 612854219, 612854221, 1206378325다. 원본의 좌표·노드 순서를 바꾸거나 떨어진 선형을 직선으로 이어 붙이지 않았다. OSM 공식 문서는 승객용 승강장을 중심선으로 지도화할 수 있음을 설명한다: https://wiki.openstreetmap.org/wiki/Tag:highway%3Dplatform . 독립 검토 기록은 peer_connection_review.md, 경로는 entrance_9_1_path.json이다.

서울역 9-1출구에서 기존 승차지까지의 지도상 거리는 64.364193023m, CPBC 지도상 대체점까지는 2,139.701399725m다. 기존 승차지의 투영 위치도 차로 주변에서 6번승강장 선형으로 옮겨졌다. 따라서 단순히 출발점 하나만 추가한 결과가 아니며 전체 정책과 지표를 다시 계산했다. 이전 961.9→649.5m, 312.4m, 87.1%, 21개 분모는 현재 보고서 수치가 아니다.

## 새 결과

- 출발점 22개·계산 가능 22개, 안내 후보 50개, 추가 2곳 조합 1,225개.
- 도달수 우선 배치: 도달 22개, 최대 추가보행 1,392.793419457m.
- 최대 추가보행 최소 배치: 도달 11개, 최대 추가보행 1,007.156906486m.
- 두 배치의 경로별 비교: 11개 개선·11개 악화. 최대 추가보행은 385.636512971m 감소하지만 최대 전체 이동거리는 늘어난다.
- 전체 추가보행 합계 최소 배치: 도달 21개, 최대 추가보행 1,374.899581615m, 최대 전체 이동거리 3,384.182022323m. 이 자료에서는 최대 전체 이동거리 최소 배치와 선택 위치가 같다.
- 안내 0·1·2곳을 각기 다시 최적화한 최대 추가보행: 1,597.210091834 / 1,392.793419457 / 1,007.156906486m. 개선 경로 수는 각각 0 / 21 / 11개다. 1곳을 유지한 채 1곳만 더하는 누적 실험으로 해석하면 안 된다.
- 선택한 2곳 배치의 평균 거리 구성은 기존 접근 518.500611448m, 승차지 변경 1,503.983375382m, 늦은 인지 333.061614017m, 전체 2,355.545600847m다. 승차지 변경은 증가거리 합의 81.8697083665%다.
- 사전 인지 조건의 승차지 변경 추가거리가 500m를 넘는 경로는 22개, 1,000m를 넘는 경로는 20개다.

journeys.csv는 네 정책×22개 출발점의 행별 결과다. policy_summary.csv는 정책별 요약, budget.csv는 수량별 재배치, same_two_signs_by_origin.csv는 같은 수량 비교다. location_sensitivity.csv의 H500·H1000은 현장 운행 가능한 승차 대안이 아니라 경로 위 위치를 바꾸는 보완 시나리오다. 본문에서는 이를 대표 정책 성과로 사용하지 않는다.

## 접근성 분석의 발전과 한계

계단과 명시된 휠체어 통행 제한을 제외하면 새 경로 미산출 3개, 출입구 자체의 접근 제한 1개, 경로가 남지만 현장 확인이 필요한 18개로 나뉜다. 계단만 제거해도 같은 3개가 끊기는지 독립 검산했다. 출입구 22개의 휠체어 접근 태그는 이용 가능 1·불가 1·누락 20이다. 경로 18개를 휠체어 이용 가능으로 판정하지 않았다.

서울역 1번(GTX-A)·2번(공항철도) 출입구는 같은 계단 way331947404를 통과하며 계단 길이 합은 각각 25.272953925m다. 지도상 ‘출입구 1’(노드5348913429)은 여러 계단을 통과하며 합계 152.938216516m다. 수치는 높이나 계단 수가 아니다. 해당 출입구는 행사일 원본에 역명이 없어 본문에서 특정 역의 출구로 단정하지 않았다. 회현역 4번출구의 ‘휠체어 접근 불가’는 지도 등록 정보이며 현장 재확인이 필요하다.

실제 이용 가능 경로에는 대체 출입구·엘리베이터 가동·지상 보도·턱·경사·횡단·행사일 통제·대기 장소·휠체어 차량 승차가 연속해서 확인돼야 한다. 현재 모형은 일반도로 보행과 가까운 지도 선형으로의 투영을 가정한다. 출입구나 경로 수를 실제 피해 인원·장애인 수·수요로 바꾸지 않는다.

## 독립 검산

하위 에이전트 1명이 직접 후보를 구성하고 1,225개 쌍을 별도 열거해 네 정책의 위치·도달수·최대/합계 추가보행·최대 전체 이동거리를 대조했다. 직접 최단경로 평가 함수로 88행을 비교한 최대 차이는 약 1.82e-12m였다. 결과는 peer_policy_verification.json이다. 이는 계산 일치 검증이며 실제 현장 접근성·안내 인지율·정책의 인과효과 인증이 아니다.

추가 단위 검사 5개는 승객용 선형 허용, 접근·방향·면 제한 유지, 택시·차량전용 제외, 폐합 외곽선 제외, 인접하지만 노드를 공유하지 않는 선형에 임의 연결을 추가하지 않음을 확인한다.
