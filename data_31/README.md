# 수정31: 정책 권고와 공식 근거 보강

이 문서의 합계 최소 권고와 관련 계산은 **수정31 당시의 기록**이다. 수정33에서 최대 추가보행 최소 배치로 최종 권고를 바꿨으므로, 현재 권고의 근거와 경로 손익은 `data_33/README.md`와 `policy_choice.json`을 우선한다. 시설·AI·탄소 근거는 계속 유효하다.

확인일은 2026-10-18이다. 공간 모형과 거리 원값은 `data_29`를 유지했으며, 이번에는 정책 판단·접근시설의 해석·AI의 실제 수행·탄소 계산 예시를 보강했다.

## 재현

Python 3.12 표준 라이브러리로 `python data_31/verify_revision_evidence.py`를 실행하면 AI 대조 25개 항목, 권고 배치의 우선 대상 4곳, 탄소 예시를 검산한다. 네트워크와 AI API는 호출하지 않는다. 이미 생성된 AI 결과를 검사하는 것이며 새로운 AI 추출을 재실행하는 코드는 아니다.

- `policy_and_carbon_checks.json`: 추가보행 합계 최소 권고안, 도달수 우선안 대비 합계 29.199% 감소, 최대 전체 이동거리, 4곳의 일반 보행경로 손익, 탄소 가정 계산.
- `access_crosscheck.md/json`: GTX-A 서울역 1번출구 엘리베이터를 명시한 공식 공지, 공항철도 서울역 시설의 존재, 확인하지 못한 개별 연결과 행사일 가동 범위, 공식 양식 확인.
- `ai_selection.json`: TOPIS 메인 10건 중 제목에 ‘버스’와 ‘우회’가 함께 든 첫 5건을 반환 순서대로 선택한 규칙과 평가 필드.
- `ai_sources.json`: 해당 5건의 제목·본문 텍스트·게시일·URL과 해시. 불필요한 작성자 정보나 조회수, 첨부파일은 포함하지 않았다.
- `ai_predictions.json`: 이 대화의 주 Codex 에이전트가 원문을 읽어 추출한 값. 별도 API 호출은 없었다.
- `ai_reference_peer.json`: 예측값을 보지 않은 하위 에이전트가 같은 원문에서 만든 별도 대조값과 각 필드의 근거.
- `ai_evaluation.json`: 5건 × 5개 필드의 일치 검사. 빈 노선번호 배열 1건도 평가에 포함했다.
- `peer_final_review.md`, `peer_final_checks.json`: 같은 하위 에이전트의 보고서 재검토와 별도 수치 대조.

선택한 공지는 6237·6236·6228·6225·6223이며 2026-10-12~16 게시 자료다. 공간 모형의 4월 행사 공지와는 다른 검사용 표본이며, 게시된 본문과 제목만 읽었다. 날짜는 제목이 지칭하는 회차, 시각은 행사 자체보다 우회·통제 시간을 우선했다. 명시된 전체 노선 수가 없을 때 완결된 노선 목록이나 상호 구분된 하위 유형을 합산했으며 이 사실을 대조표에 표시했다.

6236의 ‘07:30~09:10(2시간)’은 시각과 지속시간이 일치하지 않는다. 09:10을 보존하고 상충을 기록했다. 6223은 본문에 반복기간이 나오므로 제목의 10월18일 회차와 구분했고, 원문의 24시도 보존했다. 6225의 33개는 시내 31개와 열거된 마을 2개를 더한 계산값이다.

## 해석 범위

25/25는 두 AI 독해의 원문 기반 추출 대조 결과다. 사람 정답표 정확도, 독립 모델의 일반 성능, 첨부도면 OCR, 승차 좌표 추출, 검수시간 절감률은 측정하지 않았다. 사람 검수 평가를 실시하려면 별도 공지와 독립 사람이 만든 정답표를 확보하고, 평가 전 완료 기준과 누락·미확인 처리 규칙을 고정해야 한다. 시간 평가는 동일 공지를 먼저 읽은 학습효과를 피하도록 문서·작업 순서를 교차 배정하고, 수작업과 AI 수정 방식의 원문 대조 완료까지 기록한다. 세부 방법과 빈 기록 양식은 `data_30`에 있다.

‘지도상 연결 확인 불가’ 3곳은 실제 접근 불가 3곳이 아니다. GTX-A 공식 공지는 같은 명칭의 출구 엘리베이터를 안내하고, 공항철도 자료는 역 수준의 시설을 확인한다. 시설과 OSM 시작점의 일대일 좌표 대응, 행사일 운영, 임시 승차지까지 연속된 계단 없는 동선은 확인하지 못했다. 역명이 없는 출입구는 번호만으로 기관 시설을 붙이지 않았다.

우선 대상 4곳의 비악화는 일반 보행경로를 비교한 결과로, 계단 없는 동선까지 보장하지 않는다. 확인된 대체 동선을 입력한 후 동일 기준을 다시 적용하는 정책 규칙을 제안했다. 탄소의 7.0224g/대상 이동 1회는 전환 방지 1%·차량거리 5km·1인·15km/L 가정에 따른 자동차 연소 CO₂ 회피 예시이며 순감축 실적이 아니다.
