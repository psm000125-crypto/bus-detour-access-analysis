# AI 활용 기록: 정책 비교와 일반화 한계

작업일 2026-10-17. 서비스는 Codex 데스크톱이다. 배포판의 정확한 모델 버전 식별자는 이 결과물에서 확인하지 못했으므로 임의로 기재하지 않는다.

실제 사용자 요청:

> ㅇㅇ 그럼 계속 발전시켜봐. 공모전의 취지에 맞아야한다?

이전 사용자 선택은 공개자료만 사용한다는 것이었다. 현장 조사·개인 이동 이력은 수집하지 않았다.

## 사용 범위

| 단계 | AI 활용 | 남긴 근거·한계 |
|---|---|---|
| 목적 재검토 | 공모전의 사람 중심 이동·형평성·지속가능성 취지와 연구 질문 연결 | 공식 공고 재확인. 심사 점수나 수상 가능성은 추정하지 않음 |
| 대조군 보완 | 최다 여정 기준에 효과를 고려한 동률 처리 추가 | 같은 후보가 선택됨. 개선폭을 부풀리기 위한 약한 대조군을 유지하지 않음 |
| 공간 확장 | 확보한 추출본 내 반경 500m의 OSM 출입구 노드를 연결 여부와 무관하게 모두 선택 | 22개 중 1개 미해결 보존. 추출 경계가 원 전체를 포함하지 않아 지역 전수로 제시하지 않음. 노드 수를 이용자 수로 해석하지 않음 |
| 수정 분석 | 기존 후보 일반화 실패 후 21개 계산 가능 여정에서 재산정 | `adaptation_contract.json`에 사후 수정임을 명시. 독립 검증으로 부르지 않음 |
| 수치·그림 | Python, NetworkX, GeoPandas를 이용한 조건부 계산 | 모형 테스트와 표 정합성 확인. 지리적 사실 검증과 구분 |
| 공개 지도 읽기 | 카카오맵 UI의 현재 장소별 도보 거리 전사 | PNG·텍스트 보존. 과거 승차 위치나 실제 이용자 효과를 검증한 자료가 아님 |
| 문서 | 방법·정책 비교·반대 결과·한계 서술 | 탄소량·인지율·이용자 수를 생성하지 않음 |

위 표는 분석 절차 요약이며 추가적인 실제 프롬프트 원문인 것처럼 제시하지 않는다. 공식 제출 시 현재 대화와 앞선 사실 추출 기록의 필요한 부분을 함께 보존한다.

## 사람 확인과 분리

새로운 현장 확인자·독립 검수자·시민 실험은 없다. AI가 앞선 AI 전사를 다시 확인한 작업을 사람 검증으로 표시하지 않는다. 스킬·코드 테스트 통과를 모델의 지리 정확도나 이용자 효과 정확도로 제시하지 않는다.

원본 파일, 분석 계약, 원본 해시, 실행 코드, 여정별 CSV, 손해 여정 수를 함께 남겨 추후 사람이 검토할 수 있게 했다. 실제 운행·물리적 안내 배치·외부 게시·공모전 접수는 수행하지 않았다.
